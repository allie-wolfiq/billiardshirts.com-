# billiardshirts.com · Website concept

Static design concept for **Billiard Shirts** (Puzz Billiards is the first brand), prepared by Quix Sites for client presentation.

Live preview: GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Pages
- `index.html` Homepage
- `product.html` Product page (colour, size, quantity and gallery are clickable)
- `shop.html` Shop / collection (category chips and mobile filter drawer work)
- `about.html` About
- `contact.html` Contact

## Notes
- Concept only. No real cart or checkout; forms show a confirmation and send nothing.
- Prices, shipping times, return policy and product names are placeholders.
- Product images are temporary stock photos from Unsplash (Unsplash licence). Puzz Billiards artwork will be applied to Printify mockups at build.
- Final build target: Shopify + Printify.
